Intermediate-Task 2
This project is a professional, interactive Services/Portfolio web page designed with HTML5, CSS3, and vanilla JavaScript. 
It demonstrates advanced frontend techniques including:

- Responsive CSS Grid layout for services/portfolio cards  
- Smooth hover effects with scale, shadow, and overlay  
- Scroll animations triggered with IntersectionObserver and CSS transitions  
- Category filters with smooth transitions for showing/hiding cards  
- Modal popup to display detailed project/service information  
- Dark/Light mode toggle with saved user preference  
- Call-to-action section with clear conversion goals  
- Fully responsive across desktop, tablet, and mobile  

The design focuses on modern UI, interactivity, and accessibility while using no external libraries. 
It’s a clean example for building a real-world services or portfolio showcase page.
